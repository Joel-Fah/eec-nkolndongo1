# 0010 — pawaPay for payments (later)
**Status:** Proposed · 2026-10-19
**Context:** Giving relies on MTN MoMo and Orange Money. pawaPay lists Cameroon (MTN_MOMO_CMR,
ORANGE_CMR, XAF).
**Decision:** Phase 1 shows merchant numbers/bank details only. Phase 3 integrates pawaPay behind the
`payments` module interface so the provider is swappable.
**Consequences:** Need merchant onboarding and confirmation of deposit support for both providers.
