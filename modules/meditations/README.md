# Module `meditations` — Méditations

**Purpose.** The yearly meditation programme (imported from CSV), with passages shown as references and the Bible text from the parish's Bible service.

**Data kept.** `meditation_plans`, `meditation_days` (date, headline, readings, psalm, reflection, verse), `bible_verses` (translation, book, chapter, verse, text). **No personal data.**

**Why each field.** To publish the daily meditation and passages.

**Exposure.** Public once published. Admin: `meditations:read|edit|publish`.

**Retention.** Kept (public content).

**Owners.** Éditeur.
