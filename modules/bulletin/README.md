# Module `bulletin` — Bulletin du dimanche

**Purpose.** The Sunday bulletin: assembled from the site's own data (this Sunday, agenda, news), corrected, published and printed.

**Data kept.** `bulletins` (week, state, title, blocks, PDF address, who wrote it). The blocks come from content that is already public; it may name people who agreed to appear.

**Why each field.** The week and blocks: to compose and print. Author: accountability.

**Exposure.** Admin: `bulletin:edit|publish`. Public: the published bulletin.

**Retention.** Kept (public content).

**Owners.** Secrétariat, éditeur.
