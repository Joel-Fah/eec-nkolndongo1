# Mon compte

## Ce que c’est

**Mon compte** regroupe tout ce qui vous concerne : votre identité, votre profil de membre de la paroisse, votre mot de passe, vos préférences et les appareils où vous êtes connecté. Les personnes de l’équipe font aussi partie de la communauté : le profil se complète donc ici, comme pour tout membre.

## Compléter mon profil

1. Dans **Mon profil complet**, lisez ce qui est demandé et pourquoi, cochez la case (jamais cochée pour vous), puis **Activer mon profil complet**.
2. Renseignez ce que vous voulez : date de naissance, genre, quartier, ville, situation matrimoniale, profession. Tout est facultatif et modifiable.
3. Ajoutez une photo si vous le souhaitez. L’équipe qui gère les membres la voit ; le public, jamais. Si vous vous connectez avec Google, votre photo Google est déjà là : gardez-la ou choisissez-en une autre.
4. Avec **Utiliser ma photo comme avatar**, votre photo devient votre avatar dans le menu. Sans cela, un avatar généré vous représente.

> Retirer votre accord efface vos détails et votre photo.

## Mot de passe et connexion

- Si vous vous connectez avec **e-mail et mot de passe**, changez le mot de passe ici ; les autres appareils sont déconnectés.
- Si vous vous connectez avec **Google**, il n’y a pas de mot de passe à changer.
- Dans **Appareils**, vous pouvez fermer une session que vous ne reconnaissez pas.

## Bon à savoir

- Une petite marque **À compléter** près de votre avatar rappelle que le profil n’est pas terminé. Elle ne bloque rien.
- Votre langue et votre thème (clair, sombre) se règlent dans **Préférences**.
