# Inviter un collègue

1. Ouvrez **Utilisateurs**, puis **Inviter quelqu'un**.
2. Saisissez son nom et son e-mail, et choisissez son **rôle** (ce qu'il pourra faire). Pour un responsable de groupe, choisissez aussi le **groupe**.
3. Un lien d'invitation est créé. Il est dans la **Boîte d'envoi** : envoyez-le à la personne (il est valable 72 heures).
4. La personne choisit son mot de passe via le lien.

> Donnez le rôle le plus petit qui suffit. Vous pourrez toujours l'élargir.
