# Suivre mon groupe

## Ce que c'est

« Mon groupe » est pour les **responsables d'un groupe** (et le secrétariat) : vous voyez les personnes de **votre** groupe, les demandes pour le rejoindre et quelques chiffres. Pour créer ou configurer les groupes eux-mêmes (nom, page publique, responsables), c'est l'écran **Groupes**. Vous ne voyez jamais un autre groupe que le vôtre.

## Pas à pas

1. Si vous avez plusieurs groupes, choisissez-en un en haut.
2. **Demandes pour rejoindre** : **Accepter** ou **Refuser**. Vous pouvez écrire un petit message que la personne verra avec la réponse.
3. **Membres** : une carte par personne, avec son avatar, son rôle et sa date d'arrivée. Les boutons **Appeler** et **WhatsApp** n'apparaissent que si la personne a choisi de partager son numéro avec le groupe.
4. **Retirer** une personne : un motif est obligatoire. Il reste dans le journal d'activité ; ni la personne ni le public ne le voient.
5. **Annonces** ouvre l'écran des annonces du groupe.

## Les chiffres

- **Membres** et **arrivées ce mois-ci**.
- **Âges** : affichés seulement à partir de 5 personnes dont l'âge est connu, pour ne désigner personne.

## Bon à savoir

- L'**export CSV** est réservé aux personnes qui ont ce droit : il est limité à votre groupe et chaque export est noté dans le journal.
- Appartenir à un groupe ne rend le nom de personne public.
- Les demandes sans réponse sont effacées au bout de 6 mois.
