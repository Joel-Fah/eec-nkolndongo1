# Suivre la Fête des Moissons

## Ce que c'est

Une **campagne** de la Fête des Moissons fixe un **objectif** (en FCFA) et des **dates**. Le site montre une **corbeille qui se remplit** à mesure que les sommes reçues sont **validées**. Deux personnes interviennent : le **trésorier** saisit les sommes, une **autre personne** (le secrétariat) les valide. Seul le **total validé** est public : jamais une somme isolée, jamais un nom.

## Pas à pas

1. **Secrétariat** : ouvrez **Fête des Moissons**, puis **Nouvelle campagne**. Les dates viennent des Réglages ; indiquez l'**objectif**, une courte présentation, une photo si vous voulez, puis **Publier**.
2. **Trésorier** : onglet **Sommes reçues**. Une ligne par somme (par exemple le total d'un dimanche) avec sa date. Le groupe est facultatif. **N'écrivez jamais le nom d'un donateur**, même dans la note interne.
3. **Secrétariat** : relisez chaque ligne avec la réalité, puis cliquez sur **Valider**. On ne peut pas valider une somme qu'on a saisie soi-même.
4. Facultatif : onglet **Groupes** pour donner un objectif à un groupe. C'est un encouragement : le site liste les groupes par ordre alphabétique, sans classement.

## Bon à savoir

- Si l'on modifie le montant d'une somme déjà validée, sa validation est retirée : il faut la valider de nouveau.
- Le site ne reçoit **aucun paiement** : les moyens de donner affichés sont ceux validés dans les Réglages.
- Le trésorier et le secrétariat doivent avoir ces droits : à donner dans **Rôles** (le trésorier : lire et saisir ; le secrétariat : lire, modifier et valider).
