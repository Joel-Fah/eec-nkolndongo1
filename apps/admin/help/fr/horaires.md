# Mettre à jour les horaires

Les horaires des cultes et rencontres se gèrent dans **Cultes et horaires**.

1. Ouvrez **Cultes et horaires** et choisissez le jour.
2. Cliquez sur une ligne pour la modifier, ou sur **Ajouter** pour une nouvelle.
3. Enregistrez.

> Un horaire est **un fait** : il n'apparaît sur le site que lorsqu'il est **approuvé** par une personne autorisée. Toute modification retire l'approbation, le temps d'être relue.

Pour un jour férié ou un culte exceptionnel, créez plutôt un événement dans l'Agenda.
