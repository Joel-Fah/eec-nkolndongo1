# Écrire une annonce de groupe

## Ce que c'est

Une **annonce** est un court message pour les membres d'un groupe : une réunion déplacée, un rappel, une bonne nouvelle. Une fois publiée, chaque membre la reçoit dans « Mon espace » (onglet Groupes) et en **notification**. Il n'y a ni e-mail ni SMS. Seuls les membres du groupe la lisent.

## Pas à pas

1. Choisissez le **groupe** (vous ne voyez que les vôtres).
2. **Nouvelle annonce** : un titre et un message en français ; l'anglais est facultatif (sinon le français est montré).
3. Facultatif : un **lien** (une page du site comme `/fr/agenda/`, ou une adresse https) et un **dernier jour d'affichage**.
4. **Enregistrer** : l'annonce reste un **brouillon**, personne ne la voit.
5. **Publier** : les membres reçoivent la notification. Publier deux fois n'envoie pas deux notifications.
6. **Retirer** quand c'est fini : elle disparaît de Mon espace et ses notifications sont closes.

## Bon à savoir

- Le message est court (1 000 caractères au plus) : mieux vaut un lien vers l'événement ou le formulaire.
- Un membre peut couper les notifications d'annonces dans Mon espace ; l'annonce reste visible dans Groupes.
- Une annonce retirée est effacée 12 mois plus tard.
