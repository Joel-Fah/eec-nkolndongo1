# Aide-mémoire : Validateur de contenu

## Ce que c’est

Cette fiche tient sur une page, à imprimer : elle résume ce que fait un **validateur de contenu** (celui qui relit les informations avant qu’elles soient publiques).

## Pas à pas

1. Menu **À valider**.
2. Comparez chaque ligne avec la réalité.
3. Exact : **Valider**. Faux : **Demander une correction**.
4. Un doute : ne validez pas.

Vous ne publiez pas d'actualités et ne changez pas les rôles.

Aide complète : menu **Aide**.
