# Répondre aux messages reçus

## Ce que c’est

**Messages** est la boîte de réception du formulaire de contact du site : ce que les visiteurs écrivent à la paroisse. Chaque message a un état (nouveau, pris en charge, traité) pour que personne ne réponde deux fois.

## Pas à pas

1. Ouvrez **Messages**. Les nouveaux sont marqués.
2. Cliquez sur un message pour le lire. Cliquez sur **Prendre en charge** pour dire « je m'en occupe ».
3. Répondez à la personne par WhatsApp, téléphone ou e-mail, selon ce qu'elle a indiqué.
4. Ajoutez une **note interne** si utile (visible seulement par l'équipe), puis **Marquer comme traité**.

## Demandes de prière

Elles sont **confidentielles** : seules les personnes autorisées les voient. Ne les copiez ni ne les transférez.

## Bon à savoir

- Les messages sont effacés automatiquement après un délai (12 mois après traitement ; 3 mois pour les prières).
- Pour supprimer un message plus tôt, utilisez **Supprimer** (action définitive).
