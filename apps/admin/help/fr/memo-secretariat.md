# Aide-mémoire : Secrétariat

Vous gérez les messages, les membres et la boîte d'envoi.

1. **Messages** : lire → Prendre en charge → répondre → Marquer comme traité.
2. **Boîte d'envoi** : copier le lien → l'envoyer → Marquer comme transmis.
3. **Utilisateurs** : Inviter quelqu'un → rôle (et groupe) → envoyer le lien.
4. **Prières** : confidentielles. Ne pas copier ni transférer.

Aide complète : menu **Aide**.
