# Publier une actualité

Une actualité est un texte qui apparaît sur la page **Actualités** du site : une annonce, un compte rendu, une invitation.

## Pas à pas

1. Ouvrez **Actualités** dans le menu, puis **Écrire une actualité**.
2. Écrivez le **titre** et le **texte**. Le résumé est facultatif : sans résumé, le début du texte est utilisé.
3. Ajoutez une photo si vous en avez une (voir « Ajouter des photos »).
4. L'anglais est facultatif. Si vous le laissez vide, les visiteurs anglophones verront le français avec une mention.
5. Cliquez sur **Publier**. L'actualité est visible sur le site en deux minutes environ.

> Votre travail est enregistré automatiquement. Tant que vous n'avez pas publié, personne ne le voit.

## Bon à savoir

- **Aperçu** : un lien secret, valable 3 jours, pour montrer le brouillon à quelqu'un qui n'a pas de compte.
- **Retirer du site** : l'actualité redevient un brouillon.
- Un responsable de groupe ne peut écrire que pour son groupe.
