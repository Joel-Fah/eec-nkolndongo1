# Add a sermon

## What it is

A **sermon** has a **text page** on the site and, if you have them, a **YouTube video** and **links** (for example the audio on Google Drive). The site stores no audio file: it points to where the file lives. **Only the title is required.**

## Step by step

1. Open **Prédications** (sermons), then **Ajouter une prédication** (add a sermon).
2. Write the **title**. Add the date, a summary, and if you like the notes or outline.
3. **Bible passages**: choose the book, chapter and verses. Only the references are shown (not the text).
4. **Video**: paste the YouTube address. It only loads if someone presses « Lire la vidéo » (play the video).
5. **Links**: add the address (it must start with https://) and a name, for example « Écouter l'audio » (listen to the audio).
6. Click **Publier** (or schedule it).

## Audio on Google Drive

1. Put the file in Drive, then **Share** → “Anyone with the link” → **Viewer**.
2. Copy the link and paste it in **Links**.
3. Always keep the original in Drive: it is the parish archive.

> The site hosts no audio file and processes none: it opens your link in a new tab.

## The preacher's name

It only shows if the person agreed: tick the box only in that case. « Reprendre depuis un dimanche » copies the date, readings and name, but **never** the agreement.
